# WordPress 后台操作指南

> 后台地址：`https://你的域名/wp-admin`

---

## 一、博客文章管理

### 发布新文章

1. 后台左侧菜单 → **文章** → **写文章**
2. 填写标题和正文内容
3. 右侧设置：
   - **分类目录**：选择 Update / Informasi / Trivia / Event 之一
   - **特色图片**：上传文章封面图（建议尺寸 800x450px）
   - **摘要**：可选，用于文章列表页的简介文字
4. 点击 **发布**

### 设置外链

如果文章需要点击后跳转到外部网站（而不是打开详情页）：

1. 编辑文章，页面下方找到 **外链 URL** 输入框
2. 填入外部链接地址（如 `https://www.detik.com/...`）
3. 保存后，前台点击该文章卡片会在新标签页打开外链

> 留空则点击后正常跳转到文章详情页。

### 管理分类

后台 → **文章** → **分类目录**

Blog 页面使用以下分类进行筛选：
- `Update` — 产品更新
- `Informasi` — 资讯
- `Trivia` — 趣味知识
- `Event` — 活动

## 二、媒体报道管理

> 用于 Blog 页面顶部的「Artikel Terbaru」横向滚动卡片区域。

### 添加媒体报道

1. 后台左侧菜单 → **媒体报道** → **添加媒体报道**
2. 填写：
   - **标题**：报道标题
   - **特色图片**：报道封面图
   - **外链 URL**：点击卡片跳转的目标地址（必填）
3. 发布

### 调整排序

编辑媒体报道时，右侧有 **排序** 字段，数字越大排越前面。相同排序值按发布日期倒序排列。

## 三、首页内容编辑

首页内容通过 ACF（Advanced Custom Fields）字段管理。

1. 后台 → **页面** → 找到 **Home** → 编辑
2. 页面下方会看到以下可编辑区域：

### Hero 区（顶部大图区域）

| 字段 | 说明 |
|------|------|
| Hero 标题 | 大标题文字，支持 `<br>` 换行 |
| Hero 副标题 | 副标题文字 |
| Hero 图片 | 右侧手机展示图 |
| Hero CTA 文字 | 按钮文字（如 "Download App"） |
| Hero CTA 链接 | 按钮跳转地址 |

### Features 区（功能介绍）

| 字段 | 说明 |
|------|------|
| 功能区标题 | 区域标题 |
| 功能区描述 | 区域描述文字 |
| 功能区图片 | 手机展示图 |
| 功能列表 | 可增减的功能标签列表 |

### How-to 区（使用步骤）

| 字段 | 说明 |
|------|------|
| 使用步骤标题 | 区域标题 |
| 使用步骤图片 | 手机展示图 |
| 使用步骤列表 | 每个步骤包含标题和描述 |

### Testimonials 区（用户评价）

| 字段 | 说明 |
|------|------|
| 评价区标题 | 区域标题 |
| 评价列表 | 每条评价包含内容、姓名、头像 |

> 修改后点击 **更新** 保存，前台刷新即可看到变化。

## 四、其他页面

### Explore 页面（视频教程）

- 数据来源：**优先从 API 接口获取**
- ACF 备用字段：后台 → 页面 → Explore Lemomo → 编辑
  - `explore_title`：页面标题
  - `explore_subtitle`：页面副标题
  - `explore_main_video_url`：主视频播放地址
  - `explore_main_thumbnail`：主视频封面图

> 当 API 接口可用时，视频列表从接口获取；API 不可用时使用 ACF 字段内容。

### Event 页面（线下活动）

- 数据来源：**优先从 API 接口获取**
- ACF 备用字段：后台 → 页面 → Event → 编辑
  - 活动倒计时配置（下一场活动标题、日期等）
  - 活动列表（标题、日期、地点、描述、图片）

### FAQ 页面（常见问题）

- 数据来源：**优先从 API 接口获取**
- ACF 备用字段：后台 → 页面 → FAQ → 编辑
  - FAQ 标题和搜索框占位文字
  - FAQ 分类及问答列表

### About Us 页面

- ACF 字段：后台 → 页面 → About Us → 编辑
  - Hero 标题和描述
  - Mission 标题和描述

## 五、全局设置

### API 接口配置

后台左侧菜单 → **全局设置** → **接口配置**

| 字段 | 说明 | 默认值 |
|------|------|--------|
| App API 域名 | 视频、活动、FAQ 数据的接口地址 | `http://49.232.128.174:48082` |

> 所有接口均为公开接口，无需登录鉴权。修改后需清除缓存才能生效。

### 清除 API 缓存

API 数据缓存 1 小时。如需立即刷新，使用以下命令：

```bash
cd /opt/lemomo-wordpress
docker compose -f docker-compose.prod.yml --env-file .env.prod run --rm wpcli transient delete --all --allow-root
```

## 六、导航菜单管理

后台 → **外观** → **菜单**

当前导航菜单包含：Home / Explore Lemomo / About Us / Event / Blog / FAQ

可以：
- 拖拽调整菜单顺序
- 添加或删除菜单项
- 修改菜单项的显示文字

修改后点击 **保存菜单**。

## 七、媒体文件管理

后台 → **媒体** → **媒体库**

- 支持上传图片（JPG/PNG/SVG/WebP）和视频（MP4）
- 图片建议压缩后再上传，以保证页面加载速度
- 上传的文件存储在 `wp-content/uploads/` 目录

> 如果上传失败，联系运维执行权限修复命令（见部署指南「日常运维命令」章节）。

---

## 八、注意事项

1. **不要在后台更新 WordPress 核心版本**，以免与主题不兼容
2. **不要随意停用 ACF 插件**，否则首页等页面的自定义字段将无法显示
3. **不要删除 Lemomo 主题**，这是网站唯一使用的主题
4. **定期备份数据库**，运维可参考部署指南中的备份命令
